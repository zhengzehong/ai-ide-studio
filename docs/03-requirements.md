# 需求规格

## 一、Dashboard（概览首页）

### 功能需求

1. **统计卡片** — 显示进行中任务数、活跃 Agent 数、今日完成任务数、活跃会话数
2. **快捷操作** — "新建任务" 和 "新建 Agent" 按钮，点击弹出表单弹窗
3. **任务动态** — 最近任务列表，显示任务名称、状态标签、当前阶段（stage）
4. **Agent 工作状态** — 各 Agent 当前状态（忙碌/空闲/待机）和正在执行的内容

### 交互规格

- 新建任务弹窗字段：任务名称、优先级（P0-P3）、指派 Agent、描述
- 新建 Agent 弹窗字段：Agent 名称、类型（下拉选）、权限等级、描述
- 统计卡片支持 hover 高亮
- 点击任务可跳转到 Workspace 查看详情

---

## 二、Workspace（三栏工作台）

### 布局

```
┌─────────┬───────────────────┬──────────┐
│ Agent树  │    交互/对话区     │ 状态面板  │
│ (240px) │    (flex-1)       │ (320px)  │
└─────────┴───────────────────┴──────────┘
```

### 左栏 — Agent 树

- 按 Agent 分组展示
- 每个 Agent 下面挂载活跃 Session
- Agent 显示状态指示灯（绿=忙碌，蓝=空闲，灰=待机）
- Session 显示正在处理的内容摘要
- 点击 Session 加载对应的交互区

### 中栏 — 交互区

- 展示选中 Session 的对话历史
- 消息类型：
  - **用户消息** — 右侧气泡
  - **AI 消息** — 左侧气泡
  - **思考块** — 可折叠的灰色区域，默认折叠
  - **工具调用** — 带状态标识（运行中/成功/失败），可展开查看结果
  - **决策点** — 黄色提示块，Agent 需要人确认时显示
- 底部输入框：支持发送消息给当前 Agent

### 右栏 — 状态面板

- 当前 Session 所属任务的详情
- 任务状态：阶段（stage）+ 已耗时
- 子任务列表
- 操作按钮：暂停 / 继续 / 终止
- Session 操作时间线（简略版）

---

## 三、TaskBoard（任务看板）

### 功能需求

- Kanban 布局，按状态分列：待办 → 计划中 → 执行中 → 已阻塞 → 审查中 → 已完成
- 每列显示任务卡片
- 卡片内容：任务名称、来源标签（human/agent/event/schedule）、当前阶段、子任务进度（✓ 2/4）
- 列头有颜色指示圆点
- 支持新建任务

### 交互规格

- 卡片 hover 抬升阴影
- 支持点击进入任务详情（跳转 Workspace）
- 新建任务按钮在右上角

---

## 四、Schedule（自动化规则）

### 功能需求

- 展示已配置的自动化规则列表
- 规则卡片信息：规则名称、触发方式（定时/事件）、关联 Agent、执行操作、启用状态
- 支持新建规则
- 支持启用/禁用切换

### 规则类型

- **定时触发** — cron 表达式，定期执行（如每天 9:00 扫描 Issue）
- **事件触发** — 监听事件后执行（如 PR 提交后自动 Review）

---

## 五、Chat 交互组件

### 消息类型详情

| 类型 | 样式 | 交互 |
|------|------|------|
| user | 右侧蓝色气泡 | 无 |
| assistant | 左侧白色气泡 | 无 |
| thinking | 灰色块，带"思考中"标签 | 点击展开/折叠 |
| tool_call | 带工具名 + 状态徽章 | 点击展开查看结果 JSON |
| decision | 黄色告警块 | 显示选项按钮 |
| status | 轻量通知条 | 无 |

### 输入区

- 多行输入框（Shift+Enter 换行）
- 发送按钮
- 可附加上下文（@文件, @代码片段）

---

## 六、Session Timeline（工作记录时间线）

### 功能

- 垂直时间线布局
- 每个节点代表一个操作：文件编辑、命令执行、测试运行等
- 节点信息：时间、操作类型、操作描述、状态
- 支持点击展开操作详情

---

## 七、非功能需求

- 全中文界面
- 所有按钮可点击并有视觉反馈
- 弹窗使用半透明遮罩 + 居中面板
- 响应式：左栏和右栏可收起
- 加载状态：骨架屏或 spinner
- 亮色主题，Cursor/Codex 风格
