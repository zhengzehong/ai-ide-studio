# 作用域与导航架构设计

## 核心问题

当前系统所有实体（Agent、Session、Task、Rule）都在单一全局作用域下运行。
但实际使用中存在两类明确不同的作用域需求：

- **全局级**：Agent 模板定义（一个"架构师"模板可用于任何项目）
- **项目级**：工作台对话、文件浏览、任务看板（都与具体项目/代码仓库绑定）

## 实体模型重新设计

### 新增实体

```
AgentTemplate（全局）           Project（全局）
├── id                         ├── id
├── name        "架构师"        ├── name     "PayFlow 支付网关"
├── type        "architect"    ├── workDir   "/path/to/project"
├── icon        "brain"        ├── description
├── systemPrompt              ├── created_at
├── runtime     "claude"       └── updated_at
├── skills[]
├── isBuiltin   true/false
└── created_at

Agent 实例 = AgentTemplate + Project 的运行时绑定（现有 Agent 表扩展 project_id + template_id）
```

### 实体关系图

```
AgentTemplate (全局)  ←──引用── Agent (项目级)  ──属于──→ Project (全局)
                                  │
                                  ├── 1:N Session
                                  │      └── 1:N Message/Event
                                  └── N:1 Task (项目级)
                                          └── 属于 Project

Rule (可选项目级)  ──属于──→ Project
```

### 现有 Agent 表变更

```sql
ALTER TABLE agents ADD COLUMN project_id TEXT REFERENCES projects(id);
ALTER TABLE agents ADD COLUMN template_id TEXT REFERENCES agent_templates(id);
ALTER TABLE agents ADD COLUMN system_prompt TEXT DEFAULT '';
ALTER TABLE agents ADD COLUMN icon TEXT DEFAULT 'bot';

-- tasks 也加 project_id
ALTER TABLE tasks ADD COLUMN project_id TEXT REFERENCES projects(id);
```

## 导航结构设计

```
┌─────────────────────────────────────────────────────────────────┐
│ 顶部栏: [Logo]  项目选择器 ▾          搜索框        Agent 运行状态  │
├────┬────────────────────────────────────────────────────────────┤
│    │                                                            │
│ 📊 │  ← 概览（全局）：跨项目总览，所有项目的 Agent/Task 汇总      │
│    │                                                            │
│ 🤖 │  ← Agent 广场（全局）：Agent 模板库，创建/编辑/管理模板      │
│    │                                                            │
│────│────── 以下需要选中项目 ──────────────────────────────────── │
│    │                                                            │
│ 💬 │  ← 工作台（项目级）：对话 + 文件浏览器（并排）               │
│    │                                                            │
│ 📋 │  ← 任务（项目级）：当前项目的任务看板                       │
│    │                                                            │
│ ⏰ │  ← 自动化（项目级）：当前项目的定时/事件规则                 │
│    │                                                            │
│ ⚙️ │  ← 设置（底部固定）：全局设置 + 项目设置                     │
│    │                                                            │
└────┴────────────────────────────────────────────────────────────┘
```

### 导航规则

| 页面 | 作用域 | 是否需要选中项目 | 说明 |
|------|--------|----------------|------|
| 概览 | 全局 | 否 | 跨项目的 Agent/Task/Session 汇总仪表板 |
| Agent 广场 | 全局 | 否 | Agent 模板管理（增删改查、提示词编辑） |
| 工作台 | 项目 | **是** | 选中项目后才能对话，文件树基于项目 workDir |
| 任务 | 项目 | **是** | 只展示当前项目的任务 |
| 自动化 | 项目 | **是** | 只展示当前项目的规则 |
| 设置 | 混合 | 否 | API Key 等全局设置 + 每个项目的 Agent 配置 |

### 无项目选中时的行为

当用户未选择项目时，点击"工作台/任务/自动化"：
- 显示引导页："请先选择或创建一个项目"
- 项目选择器高亮提示

### 左侧边栏双 Tab

| Tab | 内容 | 说明 |
|-----|------|------|
| 文件 📁 | 项目文件树 | 基于 workDir，点击文件在预览区打开 |
| 会话 💬 | Agent/Session 树 | 现有功能，选择会话切换对话 |

### 文件预览区

- **默认隐藏**，点击文件时展开（~400px 宽度）
- 支持代码语法高亮（基于文件扩展名）
- 支持 Markdown 渲染
- 支持图片预览
- 顶部显示文件路径 + 关闭按钮
- 可拖拽调整宽度

### 内置 Agent 模板

| 模板 | 类型 | 运行时 | 系统提示词核心 |
|------|------|--------|----------------|
| 架构师 | architect | claude | 系统设计、技术选型、方案评估 |
| 代码工程师 | dev | codex | 代码编写、调试、重构 |
| 代码审查员 | reviewer | claude | 代码审查、质量检查、最佳实践 |
| 测试工程师 | tester | codex | 测试编写、覆盖率分析 |
| 文档工程师 | docs | claude | 文档编写、API 文档生成 |
| DevOps | ops | codex | CI/CD、部署、监控 |

### 部署流程

Agent 模板 → [部署到项目] → 在项目中创建 Agent 实例 → 可创建 Session 对话

## 实施顺序

1. **后端**: 新增 `projects` + `agent_templates` 表，扩展现有表
2. **后端**: 新增文件系统 API（列目录、读文件）
3. **前端**: 重构导航组件，加入项目选择器和作用域分区
4. **前端**: Agent 广场页面
5. **前端**: 文件查看器组件
6. **前端**: 将现有页面接入项目作用域
