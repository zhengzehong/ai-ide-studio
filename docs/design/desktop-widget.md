# 桌面悬浮部件（Desktop Widget）设计文档

桌面悬浮部件是 Electron 模式下的常驻迷你窗口，用于在不切回主窗口的情况下了解最近有哪些 Agent 在工作、哪些工作需要确认，以及每个 Agent 当前关联的任务。

## 设计原则

- **Agent 优先**：一个 Agent 只出现一次，列表按最近活跃时间排列，不展示重复会话。
- **任务就地关联**：任务是 Agent 动态的上下文，不再单独设置任务面板；存在明确的 Session 与 Task 关联时才显示任务。
- **两行完成扫描**：每个 Agent 固定两行，第一行说明主体、项目和时间，第二行说明状态和关联任务。
- **真实状态**：运行中来自 Session 执行证据，待处理来自关联 Task 的待确认/阻塞状态，不使用 Runtime 在线状态冒充工作状态。
- **桌面融合**：窗口使用半透明磨砂表面、细边框和克制阴影，能感知桌面背景但保持文字对比度。

## Agent 显示规则

每个 Agent 选择一个代表会话，选择顺序为：

1. 正在运行的会话。
2. 关联任务处于待确认或阻塞状态的会话。
3. 有未读结果的会话。
4. 最近活跃的普通会话。

列表按代表会话最后活跃时间倒序排列，并限制为最近 20 个 Agent。

每条 Agent 动态显示：

- 第一行：Agent 图标、名称、所属项目、最后活跃时间。
- 第二行：正在执行/需要确认/已完成，以及直接关联任务标题。
- 没有关联任务时，第二行回退到会话标题或当前阶段。
- 节点颜色：绿色表示运行中，琥珀色表示需要处理，蓝色表示有未读结果，灰色表示普通完成。

## 筛选与交互

- 项目选择影响整个列表，支持查看全部项目或单个项目。
- 状态筛选支持全部、运行中、待处理、已完成。
- 点击 Agent 打开其代表会话；只有主窗口导航成功后才标记该会话已读。
- 列表加载或同步失败时保留已有数据，并提供明确的同步与重试状态。

## 偏好

Widget 保存 `pinnedProjectId`，用于重启后恢复项目筛选。历史 `pinnedAgentId` 偏好继续保留兼容，但新版界面不读取它。

## 更新机制

Widget 监听 Agent 状态、Session 活跃/完成/变更和 Task 更新事件，事件到达后重新拉取轻量 Agent 动态摘要。Widget 不订阅完整聊天内容流，完整对话仍由 Workspace 负责。

## Electron 行为

- Widget 是不可调整大小的半透明常驻窗口。
- 支持固定置顶、隐藏和打开主窗口。
- 打开代表会话时携带项目与 Session 定位信息。
