# 对话存储问题分析与功能定版文档计划

## 目标

只新增文档，不改实现代码：

1. 输出一份问题分析文档，说明当前消息相关表、历史消息查询、执行过程懒加载、性能问题和重构方向。
2. 输出一份对话功能行为定版文档，固定流式输出、历史展示、执行过程、工具调用、切换会话、WebSocket 推送等期望行为，作为后续重构的回归基线。

## 执行步骤

1. 核对当前代码中的消息查询与执行过程加载逻辑。
   - 验证：确认 `sessions.messages`、`sessions.events`、`sessions.messageEvents`、前端 `selectSession`、`buildChatRenderItems`、`loadTurnProcess` 的实际行为。
2. 编写问题分析文档。
   - 验证：文档明确说明当前现状、问题、风险、推荐重构方向。
3. 编写功能行为定版文档。
   - 验证：文档明确说明重构后不能破坏的聊天交互效果。
4. 检查工作树影响。
   - 验证：仅新增本次计划和两份文档，不修改代码。
