# Android 实时语音设备探测修复计划

## 目标

修复 Android App 实时语音把“系统语音识别服务不可用”误显示成耳机/扬声器异常的问题，并提高 Android 11+ 语音服务发现、蓝牙通信路由和手机扬声器回退的可靠性。

## 范围

- Android Manifest 增加 SpeechRecognizer/TTS 服务可见性声明。
- 原生服务检查音频路由设置结果，蓝牙失败时继续回退手机扬声器。
- 原生状态携带实际音频路由和设备名称，移动端设置页区分语音识别错误与音频设备状态。
- 增加可测试的状态映射测试，重新构建 Android debug APK。
- 不修改后端、数据库、ACP 或现有 PRD 服务。

## 验收标准

- Android 11+ 安装系统语音识别服务时，不再因包可见性限制误报“没有可用语音识别服务”。
- `setCommunicationDevice` 失败不会阻断手机扬声器回退。
- 设置页能显示“蓝牙耳机/手机扬声器/未识别音频设备”，语音识别服务缺失时显示明确原因。
- 现有单元测试、lint、build 和 Android debug 构建通过。
