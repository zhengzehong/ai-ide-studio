# PC Workspace 通用文件附件实施计划

## 目标

仅为 PC Workspace 输入区增加普通文件选择和拖拽上传。文件由 Gateway 保存到会话附件目录，发送消息时把服务端真实路径附加给 AI；现有图片 image block 行为保持不变。

## 步骤

1. 为文件名、大小、Session/Project 归属和安全落盘补失败测试。
2. 新增会话附件存储模块和鉴权 HTTP 上传路由。
3. 新增 PC 上传客户端与 Workspace 普通文件草稿状态。
4. 扩展附件按钮和拖拽交互，显示上传状态、文件名及删除操作。
5. 发送 Prompt 时追加普通文件路径说明，图片继续走现有 images 字段。
6. 补齐单元/集成测试与架构说明，执行 test、lint、build 和 diff check。
7. 自审改动，提交功能分支并合并到 prd；不重启现有服务。

## 验收标准

- 图片选择、粘贴、拖拽和 image block 不回归。
- 普通文件可通过按钮或拖拽上传，AI 收到服务端绝对路径。
- 远程 Client 不使用客户端本机路径。
- 非法文件名、目录、空文件、超限文件、跨项目 Session 被拒绝。
- 单文件默认上限 50 MiB，每条草稿普通文件最多 10 个。
- 上传失败显示中文错误，未完成上传时不能发送。
- 不新增数据库迁移，不修改移动端和全局助手，不重启 PRD 服务。
