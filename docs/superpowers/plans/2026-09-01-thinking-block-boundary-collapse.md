# 思考段结束后自动折叠实施计划

## 目标

Claude Code 输出进入工具调用、中间说明或最终回答后，已经结束的思考块立即折叠；后续出现新的思考块时重新展开；整轮完成仍由 `session:done` 兜底关闭。

## 范围

- 仅修改 PC Workspace 与共享会话渲染层。
- 不新增 ACP 事件，不修改后端协议，不改变工具调用和中间说明的展示。
- 保留用户在当前阶段手动展开/关闭的覆盖行为。

## 步骤

- [ ] 增加失败回归测试：流式但已不再活动的思考块必须折叠。
- [ ] 在 `TurnContentView` 计算最后一个活动思考块并传递上下文。
- [ ] 接入 Workspace 与 ConversationProcessBlock 两条现有渲染路径。
- [ ] 补充后续新思考块、手动覆盖和完成兜底测试。
- [ ] 运行定向测试、全量测试、类型检查、lint、构建和 diff 检查。
- [ ] 提交 commit，完成代码审查后以 `--no-ff` 合并到 `prd`。

## 验收标准

1. 思考后进入工具调用时，旧思考正文立即隐藏。
2. 思考后进入中间说明或最终回答时，旧思考正文立即隐藏。
3. 工具调用后再次产生思考时，新思考块在流式期间展开。
4. 用户手动关闭后，新 chunk 不会强制打开；完成后仍可手动展开查看。
5. 历史消息默认折叠，其他工具、文件、预览和中间说明行为不变。
