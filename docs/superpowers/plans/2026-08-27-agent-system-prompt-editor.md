# Agent 系统提示词独立编辑器实施计划

## 目标

将已部署 Agent 的系统提示词从窄版设置长表单中拆出，改为紧凑摘要入口和独立宽版编辑弹窗，同时复用现有保存链路与下一轮生效机制。

## 范围

- PC Agent 设置弹窗移除内嵌长文本框，展示配置状态、字数和编辑入口。
- 点击入口后关闭设置弹窗并打开独立系统提示词编辑弹窗，避免弹窗叠加。
- 独立弹窗只保存 `systemPrompt`，支持清空，保存失败时保留编辑内容并显示错误。
- 不修改后端、数据库、Runtime、APP 或来源模板。

## 实施步骤

1. 补充 PC 组件测试，覆盖紧凑入口、独立编辑器和独立保存参数，并确认测试先失败。
2. 新增独立编辑弹窗，调整 Agent 设置弹窗和 Workspace 的弹窗切换状态。
3. 运行定向测试、TypeScript、lint、build、全量测试和 diff 检查。
4. 自审改动，提交单一 commit，并合并到 `prd`，不重启 PRD 服务。

## 验收标准

- Agent 设置弹窗不再直接展示长 textarea。
- 系统提示词入口可识别已配置/未配置状态并显示字数。
- 独立编辑器拥有足够宽高、固定操作区和下一轮生效说明。
- 保存只更新当前 Agent 的 `systemPrompt`，取消不写入。
- 现有头像、名称和模型设置行为不回归。
