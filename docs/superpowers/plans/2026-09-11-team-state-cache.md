# 团队状态与切换缓存

目标：团队对外只计一个运行或未读单位；保留各会话状态；切换立即显示缓存，后台更新。

- [x] 补充聚合、已读边界、过时运行状态、缓存隔离的复现测试。
- [x] 统一项目摘要和团队会话摘要，补充成员消息时间和已读回写。
- [x] 缓存团队列表、选择和聊天；模型能力仅加载 Master，不阻塞历史。
- [x] 更新协议与架构说明，完成代码审查及 test/build/lint。
- [x] 提交当前分支 commit。

边界：不迁移数据库，不更改 ACP 调度，不重启或发布 PRD，不启动独立服务。
验收：多成员/多会话只计一个团队；阅读一条不清除其他条；过时 idle/running 不覆盖新事件；失败保留缓存并可重试。

## 审查与验证

- 全量 Vitest：444 个文件、2454 项通过；最后一轮团队与统计定向回归 74 项通过。
- `npm run build`、`npm run lint`、`git diff --check` 通过；构建保留现有大 chunk 提示。
- 审查修正：变更后不复用变更前的列表请求；离开后的消息请求不复用到新视图；创建完成回调不得切走用户的新选择；成员变更更新订阅，任务进度不触发列表重载。
- 已读校验整批归属后才写入，旧消息不能清掉后续回复；共享 Agent 的独立 Session 仍参与统计。
- 验证在隔离 worktree 执行，日志和测试数据使用本地隔离目录；没有启动独立应用服务或连接生产环境做交互验收。
