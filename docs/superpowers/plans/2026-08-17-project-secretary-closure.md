# 项目秘书功能闭环修复

## 目标

补齐项目秘书 PC/APP 的基础可用闭环，修复移动端详情导航、项目 Agent 范围、Thread 状态和停用调度问题，同时收紧秘书工具可见范围。

## 实施清单

- [x] 后端：归档 Thread 收到新汇报时重新打开；秘书启停同步 Cron 规则；增加秘书 Session 工具可见性判断。
- [x] PC：配置表单统一布局，支持编辑触发条件与启停；无邮件时也能管理秘书。
- [x] APP：邮箱详情可返回；配置支持项目 Agent、观察范围、触发条件和编辑管理。
- [x] 测试：补齐后端状态/规则/工具边界测试与路由、前端行为测试。
- [x] 验证：定向测试、全量测试、lint、build、diff check。
