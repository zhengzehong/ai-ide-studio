# /updates 动态会话面板样式对齐计划

## 目标

保留 `/updates` 动态面板的跨项目、项目 -> Agent -> Session 数据分组，仅将视觉语言对齐现有 Workspace 会话栏：同一字号层级、行高、间距、选中态、状态点和滚动密度。置顶签继续复用同一行样式。

## 改动边界

- 仅修改 `UpdatesSidebar.tsx`、`updates-sidebar.css` 和对应单元测试。
- 不改 `Workspace.tsx`、后端、数据接口、动态筛选语义或中间对话。
- 左栏保持定稿方案的 322px 固定宽度；跨项目分组内容通过省略号适配栏宽。

## 实施顺序

1. 抽出与 Workspace 一致的 Agent 头像/项目头/会话行视觉常量，修正动态面板当前偏大的内边距和不一致的圆角、字体、状态点。
2. 保留三层分组和动态/置顶切换；为选中行增加 Workspace 同款左侧蓝色 inset，时间和标题保持单行省略。
3. 增加 CSS/静态渲染断言，锁定 322px 宽度、对齐后的行样式、三层分组及置顶全量行为。
4. 运行定向测试、TypeScript、lint、build 和 diff 检查，提交独立分支并合并到 `prd`。

## 验收标准

- 动态/置顶数据与现有接口、点击导航完全不变。
- 动态面板视觉上使用 Workspace 同款行密度和选中态，不再出现额外大间距或独立的卡片视觉。
- 项目色带仍清晰可辨，Agent 头像与会话状态点保留，标题/时间不换行。
- `npm test` 除基线已知失败外无新增失败；`npm run lint`、`npm run build` 通过。
