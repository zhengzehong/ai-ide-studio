# ACP Diff 文件变更功能设计文档任务清单

## 目标

输出一份功能设计文档，说明如何基于 ACP diff 做“本轮文件变更”展示。本文档只描述产品功能逻辑、用户看到的效果、数据口径和实现思路，不进入代码实现细节。

## 范围

- 说明 ACP diff 能表达什么、不能表达什么。
- 说明前端如何展示本轮文件变更、历史文件变更、diff 详情。
- 说明与执行过程、工具调用、消息历史的关系。
- 说明回滚、对比、review 等能力的边界。

## 不做

- 不改后端代码。
- 不改前端代码。
- 不设计复杂 Git checkpoint / 文件 watcher / 沙箱快照系统。
- 不承诺 ACP diff 覆盖所有实际文件系统修改。

## 验收标准

- 文档位置合理，属于功能设计文档。
- 读者不看代码也能理解这个功能如何工作。
- 明确说明前端显示效果和用户操作路径。
- 明确说明数据口径：ACP diff 是 Agent 上报的修改，不等于所有真实文件修改。
