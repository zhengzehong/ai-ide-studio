# ISSUE-006 会话切换恢复一致性修复计划

## 目标

修复会话切换后运行中消息、工具调用、执行过程数量显示不一致的问题，确保切换前后同一会话的对话状态不因切换而丢失、降级或倒退。

## 步骤

1. 补单测复现：切回运行中会话时，后端返回 running message 和完整 process items，前端应恢复 streaming 状态、工具过程和数量。
2. 修复恢复逻辑：区分前端缓存、后端 DB 过程项、后端运行态，切回时用后端数据补全前端缓存。
3. 修复跳过条件：本地已有 processBlocks 但少于后端 process_item_count 时仍要拉取完整过程。
4. 验证：运行相关单测，确认 ISSUE-002 测试不回归。
5. 同步：将修复合入 prd 分支，并更新钉钉问题状态。

## 验收标准

- 运行中会话切回后仍显示生成中状态。
- 工具调用和执行过程按后端完整数据恢复。
- 执行过程数量不因切换从大变小。
- 当前分支和 prd 分支包含同一修复。
