# 团队会话完成回复保留修复

## 目标

修复团队群聊在流式输出结束后回复消失的问题，并保持 Workspace 页面和后端行为不变。

## 执行清单

1. 为 `message.done` 先于 `session:done` 的事件顺序补充回归测试。
2. 在团队快照适配器中把完成事件携带的活动 turn 转为已完成消息。
3. 验证团队聚合测试、UI 类型检查、构建和 lint。
4. 核对 `prd` 提交及运行前端来源，向用户说明正确启动入口。

## 边界

- 只修改团队聊天适配器及其测试。
- 不改 `Workspace.tsx`、后端、数据库和普通会话事件归约逻辑。
- 不结束或覆盖其他项目的 Vite 进程。
