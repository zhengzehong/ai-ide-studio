# 团队回复稳定排序修复

## 目标

让团队回复在实时完成、历史加载、刷新和加载更多后保持同一回合顺序；普通 Workspace 行为不变。

## 实施清单

- [x] 团队归集与历史分页统一使用 `started_at` 优先的排序键。
- [x] 保持数据库原始 `timestamp`、分页游标及普通会话逻辑不变。
- [x] 增加完成时间覆盖开始时间的归集/重载回归。
- [x] 运行全量测试、lint、build、TypeScript 检查。
- [ ] 独立审查通过后合并 `prd`。

## 验收标准

- 同一批消息的实时完成态和历史重载态顺序一致。
- 多成员交错完成时，回复按回合开始位置稳定排列。
- 共享 Workspace 与普通 Agent 没有行为变化。
