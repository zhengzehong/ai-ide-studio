# 对话处理中显示耗时

## 目标

在 Agent 正在处理中时，在消息底部统计区域显示转圈和已用时；完成后的耗时也统一改为紧凑格式。

## 范围

- 只显示时间，不统计输入/输出 token。
- 不改变对话流、执行过程、工具调用展示逻辑。
- 不改后端 ACP 协议。

## 步骤

1. 增加时长格式化函数
   - 小于 1 分钟显示 `Xs`。
   - 小于 1 小时显示 `XmYs`，整分钟显示 `Xm`。
   - 大于等于 1 小时显示 `XhYm`，不显示秒。
   - 验证：补纯函数单测。

2. 完成统计改用新格式
   - 将现有 `233s` 这类展示改为紧凑时长。
   - 验证：类型检查通过。

3. 流式处理中显示耗时
   - 当前会话 streaming 时每秒刷新 elapsed。
   - 在同一统计 chip 区域显示转圈 + 已用时。
   - 验证：不影响完成后 token/cost 统计。

4. 验证与发布
   - 运行测试、build、lint、diff check。
   - 提交当前分支并合并到 prd worktree。
