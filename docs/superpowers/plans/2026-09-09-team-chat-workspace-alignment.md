# 团队对话完成态与 Workspace 行为对齐

## 目标

修复团队群聊在 Agent 完成回复后内容短暂或永久变空的问题，并让团队中间区域的历史加载、自动滚动和执行过程展示与现有 Workspace 的行为保持一致。普通 Workspace 页面及其业务状态不改。

## 实施清单

1. 在团队聚合层增加完成态保护：历史刷新结果不能覆盖已有的内存消息、流式回复或执行过程；完成事件触发延迟重载，只有拿到最终历史消息后才清理临时状态。
2. 补齐团队消息列表的加载、错误、空态、历史加载和自动滚动分支，保证切换会话和流式内容变化时滚动策略稳定。
3. 对齐团队会话列表的 SessionBar 基础视觉和键盘交互，不改变团队会话接口和普通 Agent 列表。
4. 增加团队聚合、完成态保护、滚动/列表行为的回归测试。
5. 运行定向测试、TypeScript、lint 和 build，检查 Workspace 文件无修改。

## 验收标准

- `session:done` 到达早于历史持久化时，团队消息仍保留，最终历史可自动接上。
- 完成后最终回复、工具过程、文件变更不会被空查询清掉。
- 团队页切换会话自动滚到底部，用户上翻后不会被流式输出强制拉回。
- 加载、错误、空态和加载更多均有可见出口。
- 团队列表的宽度、头部、行高、选中态和基础键盘行为与 SessionBar 一致；普通 Workspace 不改。
