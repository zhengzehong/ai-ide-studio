# 团队成员派发队列接续修复

## 目标和范围

修复成员结束一轮后排队指令停滞的问题；派发失败时通知对应团队会话的 Master。
不修改任务完成语义、成员通信权限或前端，不启动或重启 PRD 服务。

## 已确认的根因

`session:done` 早于 `activePrompts` 清理。旧派发器在 done 时出队，发现仍忙后重新入队；清理后没有接续入口。
派发失败只更新任务和 UI 事件，没有通知 Master 的模型会话。

交付方式：单独提交本次修复，再合并本地 prd，保留无关改动，不重启服务。

## 验收

成员完成后自动接续后续派发，无需 Master 手动重发；单个成员不重复、不乱序，不影响其他成员。
失败时对应 Master 收到系统通知，运行中任务转为 needs_input，终态任务不被重新打开。
