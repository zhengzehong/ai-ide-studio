# 会话功能链路分析任务清单

日期：2026-05-27

## 目标

分析当前 AI IDE Studio 的会话功能链路，包括：

- 当前会话逻辑是什么
- Agent 是否都挂在会话侧
- 是否支持删除会话、重命名会话
- 后端、前端、WS、存储之间的完整调用链路
- 存在的问题、风险与可优化方向

## 执行步骤

1. 阅读后端 Session/Agent/Task/WS/Store 相关模块，梳理核心数据结构与事件流。
2. 阅读前端 Workspace/Session UI、Zustand store、WS client，梳理用户操作入口。
3. 核对创建会话、发送 prompt、Agent 状态、关闭/删除/重命名相关实现。
4. 对照架构原则检查边界、日志、持久化、错误处理、体验问题。
5. 输出现状说明、问题清单、优化方案与建议落地顺序。

## 范围

本轮只做分析与建议，不改业务代码。
