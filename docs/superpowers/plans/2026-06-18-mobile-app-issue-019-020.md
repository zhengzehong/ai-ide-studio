# Mobile App Issue 019/020 Implementation Plan

**For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans implement plan task-by-task.

**Goal:** Fix the first two registered APP bugs: transient connection loss should not send an already configured app back to token auth, and completed session list state should not lose unread/completion indicators because of stale immediate refreshes.

**Architecture:** Keep changes local to the mobile app state boundary. The connection fix changes the app-level route decision to depend on whether a server is configured, not whether the websocket is currently connected. The session list fix keeps local event-derived unread state authoritative while a delayed refresh lets backend persistence finish after `session:done`.

**Tech Stack:** React 19, Zustand, Vitest, existing desktop `wsClient`.
