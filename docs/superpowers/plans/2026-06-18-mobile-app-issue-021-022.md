# Mobile App Issue 021/022 Implementation Plan

**For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans implement plan task-by-task.

**Goal:** Fix APP conversation detail completion refresh lag and Android system back behavior.

**Architecture:** Keep the chat refresh fix inside `mobile/src/stores/chat.store.ts` by adding a delayed post-persistence refresh for current-session `session:done` and idle events. Keep Android back behavior in a small mobile routing helper/component so route policy is testable without Android runtime.

**Tech Stack:** React 19, React Router, Zustand, Capacitor Android, Vitest.

---
