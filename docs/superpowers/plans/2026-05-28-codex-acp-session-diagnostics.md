# Codex ACP 与新会话卡顿诊断

## 目标
- 找到 Codex 不能用的本地真实原因。
- 找到点击新会话卡顿的调用链路与耗时点。
- 先给出证据和修复方案，不扩大改动范围。

## 步骤
1. 检查仓库状态与现有运行日志 -> 验证是否有 Codex ACP 报错。
2. 检查 Codex ACP 本地包和用户配置 -> 验证配置字段是否被当前版本接受。
3. 做最小 `codex-acp` 复现 -> 验证错误是否脱离 UI 仍然存在。
4. 追踪 `sessions.create` 前后端链路 -> 验证新会话为什么会等待/卡顿。
5. 汇总根因、影响范围和建议修复优先级。
