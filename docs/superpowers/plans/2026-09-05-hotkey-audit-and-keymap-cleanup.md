# 快捷键审查与键位整理

## 目标

修复快捷键设置页与实际派发作用域不一致的问题，并降低会话列表中裸单键造成的误触风险。

## 改动

1. 冲突检测按实际可重叠作用域判断，覆盖 global/workspace/list；input 与 modal 保持隔离。
2. 会话置顶、标记未读、关闭改为 `mod+shift+p/u/x`，保留页面导航、`j/k`、项目切换和命令面板等既有约定。
3. 增加跨作用域和隔离作用域单元测试。

## 验收

- 设置页能提示 global 与 workspace/list 的真实冲突。
- 输入框、弹窗专用动作不被普通页面动作误判。
- 快捷键单元测试、lint、类型检查通过。
